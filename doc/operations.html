Daily Operation

Start All Sessions

bin/start-controlroom.sh

This starts all configured remote VNC sessions, then opens all local SSH tunnels. The explicit equivalent is:

venv/bin/crs-remote start --all
venv/bin/crs-tunnel open --all

Connect To A Session

venv/bin/crs-tunnel connect --session shift-main

connect opens the tunnel if needed and launches the VNC client. Use --viewer /path/to/vncviewer to force a specific viewer.

Check Status

venv/bin/crs-tunnel status
venv/bin/crs-remote status --all

crs-tunnel status reports local tunnel state. crs-remote status --all reports remote VNC and discovery-responder state.

Stop All Sessions

bin/stop-controlroom.sh

This closes all local tunnels, then stops all configured remote VNC sessions. The explicit equivalent is:

venv/bin/crs-tunnel close --all
venv/bin/crs-remote stop --all

Target Selection

crs-remote and crs-tunnel use the same selectors.

SelectorMeaning
--session NAMEOperate on one configured session.
--host HOSTOperate on all configured sessions on a host.
--allOperate on every configured session.
 
venv/bin/crs-remote start --session dcs-main
venv/bin/crs-tunnel open --host mu2e-mgr-01.fnal.gov
venv/bin/crs-tunnel close --all

For status, omitting a selector defaults to --all.

GUI

venv/bin/crs-gui

The Tunnels tab provides per-session Open, Close, and Connect actions. The Discovery tab scans via the gateway or local multicast. Use gateway mode in production because multicast does not traverse the FNAL gateway.
