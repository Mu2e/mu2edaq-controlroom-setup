Command Reference

crs-remote

venv/bin/crs-remote start --session NAME
venv/bin/crs-remote stop --session NAME
venv/bin/crs-remote status --all
venv/bin/crs-remote install --all
venv/bin/crs-remote provision --all

crs-remote runs commands over SSH with GSSAPI authentication and ProxyJump through the configured gateway. VNC lifecycle commands run as the shared session accounts.

Remote lifecycle commands call these installed scripts:

  • start-vnc-session.sh <session> <display> -g <geometry> -d <depth>
  • stop-vnc-session.sh <session> <display>
  • status-vnc-session.sh <session> <display>
  • crs-provision-desktop --session <session>

install --all runs once per unique (host, account) pair.

crs-tunnel

venv/bin/crs-tunnel open --session NAME
venv/bin/crs-tunnel close --session NAME
venv/bin/crs-tunnel status
venv/bin/crs-tunnel connect --session NAME

Each tunnel is a background SSH master connection with a control socket in ~/.crs. It forwards:

localhost:<local_port> -> localhost:<5900 + display> on the DAQ host

Tunnels log in as personal_user from controlroom.yaml when set. If no personal user is configured, they fall back to the session account.

crs-gui

venv/bin/crs-gui

The GUI provides tunnel actions and discovery scanning. Double-clicking a discovered vnc row maps it to a configured session, opens the tunnel, and launches a viewer.

Installed Server Tools

ToolPurpose
start-vnc-session.shStarts one VNC display and its discovery responder.
stop-vnc-session.shStops the discovery responder and VNC display.
status-vnc-session.shPrints name|display|port|state|responder.
vnc-discovery-responder.pyAnswers discovery queries for a VNC session.
crs-appDispatches app start/stop scripts with configured port environment variables.
crs-provision-desktopWrites XFCE .desktop launchers.

Configuration Overrides

Precedence is command line, then environment, then YAML config, then built-in defaults.

VariablePurpose
CRS_CONFIGAlternate controlroom.yaml.
CRS_APPS_CONFIGAlternate apps.yaml.
CRS_GATEWAYOverride the SSH ProxyJump host.
CRS_INSTALL_DIROverride the remote install directory.
CRS_GEOMETRYDefault geometry for direct server-side VNC starts.
CRS_DEPTHDefault VNC color depth for direct server-side VNC starts.
CRS_ANNOUNCE_INTERVALDiscovery responder announcement interval.
