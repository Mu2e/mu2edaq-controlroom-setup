Install and Setup

Prerequisites

On the client machine, use Python 3.9 or newer, Kerberos credentials for the FNAL gateway and DAQ hosts, SSH access through mu2egateway01.fnal.gov, and a VNC client.

On macOS, crs-tunnel connect uses open vnc://localhost:PORT by default. On Linux or Windows, install TigerVNC or provide another vncviewer.

On DAQ hosts, the session accounts need vncserver, startxfce4, Python 3, and application checkouts matching the install_path values in config/apps.yaml if desktop launchers should start apps.

Client Bootstrap

./bootstrap.sh

The bootstrap script creates venv/, installs the package in editable mode with GUI and test extras, and installs sibling ../mu2edaq-discovery if that checkout exists.

Install Host-Side Scripts

Get a Kerberos ticket, then install the server payload to all configured session accounts.

kinit
venv/bin/crs-remote install --all

The install command copies the files from server/ plus config/controlroom.yaml and config/apps.yaml. On the remote account it creates:

~/controlroom/bin
~/controlroom/etc
~/controlroom/log
~/.crs

It also adds ~/controlroom/bin to ~/.bash_profile and symlinks app start/stop scripts into ~/controlroom/bin when the app checkout exists.

Provision Desktop Launchers

venv/bin/crs-remote provision --all

This runs ~/controlroom/bin/crs-provision-desktop --session <name> for each configured session. The generated XFCE launchers call crs-app start <app-id> and crs-app stop <app-id>.

Verify

venv/bin/crs-remote status --all
venv/bin/crs-tunnel status

Remote status checks the VNC displays. Tunnel status checks the local SSH master control sockets.
